# 12. Text Writer

Real-time text syncing and preview application built with **TypeScript** and **HTML/CSS**.

## 🚀 Features

- **Live Preview:** Mirrors input field content to paragraph text dynamically as you type.
- **Lightweight DOM Manipulation:** Instant state updates using native event bindings.

## 🛠️ TypeScript Learnings Implemented

- **Element-Specific Assertions:** Used `HTMLParagraphElement` and `HTMLInputElement`.
- **Type-Safe Value Extraction:** Safely bound typed input string values to DOM text nodes.

## 📦 Run Locally

1. Compile TypeScript to JavaScript:
   ```bash
   npx tsc script.ts
   ```
