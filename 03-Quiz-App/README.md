![Quiz App](../screenshots/quiz-app2.png)

An interactive, responsive web-based quiz application that presents multiple-choice questions with real-time score tracking.

## 🛠️ Built With

- **HTML5** – Structure and semantics
- **CSS3** – Custom UI styling and layout
- **JavaScript (ES6+)** – Quiz state management and score calculation
