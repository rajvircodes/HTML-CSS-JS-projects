# 19. QR Code Generator

Dynamic QR Code generator application built with **TypeScript**, **HTML/CSS**, and the **QRServer API**.

## 🚀 Features

- **API Integration:** Generates custom QR codes dynamically based on user text or URL inputs.
- **Error Animation:** Triggers temporary CSS shake/error state on empty submissions.
- **Image Container Toggle:** Smoothly reveals generated image containers.

## 🛠️ TypeScript Learnings Implemented

- **Image API Types:** Leveraged `HTMLImageElement` for strict `.src` property assignment.
- **DOM Selector Accuracy:** Ensured HTML element IDs align strictly with TypeScript assertions.

## 📦 Run Locally

1. Compile TypeScript to JavaScript:
   ```bash
   npx tsc script.ts
   ```
