Registration Form

A modern and responsive user registration form with clean validation and submission handling built using HTML5, CSS3, and JavaScript.

🛠️ Built With

HTML5 – Form elements and semantic layout

CSS3 – Gradient background, modern box-shadows, and smooth transitions

JavaScript (ES6+) – Clean event listeners for form submission handling and UI reset

🚀 Getting Started

Clone the repository:

git clone https://github.com/rajvircodes/HTML-CSS-JS-projects.git

Navigate to the project directory:

cd HTML-CSS-JS-projects/Registration-Form

Open index.html in your web browser.
